Algumas propriedades CSS

Padding

Propriedade da Css. Usada para gerar um espaçamento interno ao redor do conteúdo de um elemento, situando-se entre o contéudo e a borda (border).

Margin

Propriedade da Css. Usada para gerar um espaçamento externo ao redor de um elemento, separando-o de outros elementos próximos

Border-radius

Propriedade da Css. Ela é usada para definir o arredondamento dos cantos de um elemento (divs, imagens, botões, etc.).
