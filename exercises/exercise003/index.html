Comparando linguagens

Html, Css e JavaScript

Linguagens Front-End
Linguagem Responsável por Exemplo
HTML Estruturação, marcação e organização do conteúdo de uma página web, atuando como o "esqueleto" do site. Tags como <p> para parágrafos e a <h6> para títulos.
CSS Apresentação visual, estilização e layout de páginas web. O CSS define como esse conteúdo aparece para o usuário. Usando css externo (arquivo.css) ou dentro do próprio documento html (tag <style>)
JavaScript Tornar sites dinâmicos e interativo. Ele atua no lado do cliente, permitindo manipulação de elementos HTML/CSS, criação de animações, etc. O comando alert() cria um aviso visual. O comando prompt() recebe dados do utilizador
Resumo Essas linguagens formam a base do desenvolvimento web front-end moderno, permitindo a criação de páginas funcionais, atraentes e interativas.
